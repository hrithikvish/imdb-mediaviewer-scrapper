# 🎬 IMDb MediaViewer Scrapper & Gallery

[![Scrape & Deploy](https://github.com/hrithikvish/imdb-mediaviewer-scrapper/actions/workflows/deploy-pages.yml/badge.svg)](https://github.com/hrithikvish/imdb-mediaviewer-scrapper/actions/workflows/deploy-pages.yml)
[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Gallery-f5c518?logo=github)](https://hrithikvish.github.io/imdb-mediaviewer-scrapper/)

A Python + Playwright scraper and zero-backend web application that extracts and displays full master-resolution photos, production stills, and posters from any IMDb title, person, or media viewer gallery.

---

## 🚀 Live Demo (GitHub Pages)

The static web application is deployed to GitHub Pages and showcases extracted photos in an interactive Masonry Grid and Fullscreen Carousel/Lightbox:

👉 **[https://hrithikvish.github.io/imdb-mediaviewer-scrapper/](https://hrithikvish.github.io/imdb-mediaviewer-scrapper/)**

### Web Viewer Features:
* **Per-Title Partitioned Galleries**: Title selector dropdown loads dedicated per-title JSON files (`docs/titles/{titleId}.json`) dynamically, keeping payloads lightweight even with thousands of photos.
* **Bandwidth-Optimized $\le$ 720p Previews**: Dynamic on-the-fly CDN preview scaling keeps catalog strips and masonry grids ultra-fast and lightweight (~25KB per card), while preserving true master assets.
* **On-Demand Full-Res & Direct Master Download**: View full uncompressed 4K master images on demand (`Full-Res` button) or download the original high-resolution master asset directly (`Original` button).
* **Light & Dark Theme Toggle**: Instant theme switcher in the top navigation bar, with user preference persisted in `localStorage`.
* **Masonry Grid**: Responsive image grid with dimension badges and captions.
* **Fullscreen Carousel / Lightbox**: Click any card to launch the carousel with `←` / `→` arrow keys, `Esc` to close, counter (`1 / 247`), and direct master asset downloader.
* **Real-time Filter**: Instant search filter by caption or high-res toggle (≥ 1080p).
* **Wallpaper Studio**: Generate random cinema collages (scattered, staggered, or cinema-strip layouts; 16:9, 16:10, 9:16; up to 4K) with Polaroid frames, rescatter animation, single-photo swap, and source-title filtering — then download as JPG.
* **Zero Backend Required**: Runs directly on GitHub Pages via static JSON feeds generated by GitHub Actions.

## 🏛️ Architecture

Everything runs from a single Python script plus a static site:

```
scraper.py                          # Python + Playwright scraper (local CLI & GitHub Actions)
├── extract_imdb_titles_from_text() # Free-form text → IMDb IDs (URLs, tt.../nm... IDs, search links, plain titles)
├── resolve_title_by_id()           # Canonical "Name (Year)" via IMDb Suggestion API (thread pool)
├── scrape_single_title_gallery()   # Headless Chromium: /mediaindex/ infinite scroll + JSON payload capture
├── clean_imdb_image_url()          # Strips resize/crop params → original master asset URL
├── save_title_gallery()            # Writes docs/titles/{id}.json, updates docs/titles.json
└── rebuild_titles_registry()       # --rebuild-index: regenerates the registry (stdlib only)

docs/                               # GitHub Pages site (vanilla HTML/CSS/JS, no build step)
├── index.html, app.js, style.css   # Catalog, gallery, lightbox, Wallpaper Studio
├── titles.json                     # Lightweight registry of all titles
└── titles/{id}.json                # One gallery file per title
```

## 🔍 How Extraction Works

1. **Flexible Free-Form Input & Parallel API Resolution**:
   * Accepts arbitrary text containing movie titles, IMDb URLs, IDs (`tt...`), or search URLs (`/find/?q=...`).
   * Queries IMDb's global Suggestion API in parallel (Python thread pool) to resolve canonical movie titles and release years (e.g. `Saving Private Ryan (1998)`), eliminating parsing misattribution.

2. **Complete Gallery Infinite Scroll**:
   * Targets `/mediaindex/` and scrolls `.img_gallery_pagination_loader` to extract the full gallery (e.g. 247+ photos) instead of only the first 30.

3. **Strict Gallery Scoping (Excludes Unrelated Content)**:
   * Scopes DOM extraction strictly to `a[href*='/mediaviewer/rm'] img` inside the images gallery section.
   * Discards unrelated images found on the page such as *Editorial Lists*, *User Lists*, *User Polls*, and *More to explore*.

4. **Master Resolution Cleaning**:
   * IMDb thumbnail URLs contain resize/crop parameters (e.g. `._V1_QL75_UX380_CR0,0,380,562_.jpg`).
   * The scraper automatically cleans these down to `._V1_.jpg`, recovering the **original uncompressed high-resolution master asset** (often 2000px+).

## 💻 CLI Usage

### Python Scraper (Powers GitHub Actions)
```bash
# Setup virtual environment & dependencies
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium

# Scrape default sample
python3 scraper.py

# Scrape any single IMDb movie/show URL or ID
python3 scraper.py "https://www.imdb.com/title/tt0038650/"

# Batch scrape multiple titles from free-form text or a file
python3 scraper.py --input movies.txt

# Force re-scraping of titles even if already present in docs/titles/
python3 scraper.py --force --input movies.txt

# Rebuild docs/titles.json from docs/titles/*.json (no Playwright needed)
python3 scraper.py --rebuild-index
```

### Local Preview
```bash
python3 -m http.server 8000 -d docs
# Open http://localhost:8000
```

## ⚡ GitHub Actions Automation

The repository includes a production-ready GitHub Actions workflow (`.github/workflows/deploy-pages.yml`):

1. Go to the **Actions** tab in your GitHub repository.
2. Select **"Scrape IMDb & Deploy to GitHub Pages"**.
3. Click **Run workflow**, paste any text containing 100+ IMDb URLs, movie titles, or search links, and run.
4. The workflow batch-scrapes the photos, generates partitioned `docs/titles/{id}.json` files, updates `docs/titles.json`, and deploys to your live GitHub Pages gallery automatically!
