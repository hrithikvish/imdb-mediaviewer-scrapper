# 🎬 IMDb MediaViewer Scrapper & Gallery

[![Tests](https://github.com/hrithikvish/imdb-mediaviewer-scrapper/actions/workflows/deploy-pages.yml/badge.svg)](https://github.com/hrithikvish/imdb-mediaviewer-scrapper/actions/workflows/deploy-pages.yml)
[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Gallery-f5c518?logo=github)](https://hrithikvish.github.io/imdb-mediaviewer-scrapper/)

A scalable, clean-architecture Kotlin scraper and modern web application that extracts and displays full master-resolution photos, production stills, and posters from any IMDb title, person, or media viewer gallery.

---

## 🚀 Live Demo (GitHub Pages)

The static web application is deployed to GitHub Pages and showcases extracted photos in an interactive Masonry Grid and Fullscreen Carousel/Lightbox:

👉 **[https://hrithikvish.github.io/imdb-mediaviewer-scrapper/](https://hrithikvish.github.io/imdb-mediaviewer-scrapper/)**

### Web Viewer Features:
* **Masonry Grid**: Responsive image grid with dimension badges and captions.
* **Fullscreen Carousel / Lightbox**: Click any card to launch the carousel with `←` / `→` arrow keys, `Esc` to close, counter (`1 / 57`), and a direct download master button (`💾`).
* **Real-time Filter**: Instant search filter by caption or high-res toggle (≥ 1080p).
* **Zero Backend Required**: Runs directly on GitHub Pages via static JSON feeds generated by GitHub Actions.

## 🔍 How Extraction Works

1. **Flexible Input Handling**: Pass *any* IMDb URL or bare ID:
   * `https://www.imdb.com/title/tt0038650/?ref_=tttrv_ov_i`
   * `https://www.imdb.com/title/tt0056241/mediaviewer`
   * `tt0038650` or `nm0000123`
   [`ValidateUrlUseCase`](file:///Users/hrithikvish/IdeaProjects/imdb-mediaviewer-scrapper/src/main/kotlin/org/hrithikvish/scraper/domain/usecase/ValidateUrlUseCase.kt) strips query parameters and targets the `/mediaviewer` endpoint.

2. **Targeted Amazon CloudFront CDN**:
   * Stills and posters on IMDb are hosted under `https://m.media-amazon.com/images/`.
   * The scraper discards tracking pixels, ads, and UI icons, keeping only verified media assets.

3. **Master Resolution Cleaning**:
   * IMDb thumbnail URLs contain resize/crop parameters (e.g. `._V1_QL75_UX380_CR0,0,380,562_.jpg`).
   * The scraper automatically cleans these down to `._V1_.jpg`, recovering the **original uncompressed high-resolution master asset** (often 2000px+).

## 💻 CLI Usage

### Prerequisites
* Java 17+
* Chromium / Google Chrome / Brave Browser (detected automatically)

### Run the Scraper
```bash
# Scrape default sample
./gradlew run

# Scrape any IMDb movie/show/person URL or ID
./gradlew run --args="https://www.imdb.com/title/tt0038650/?ref_=tttrv_ov_i"

# Specify a custom JSON output path for the web app
./gradlew run --args="https://www.imdb.com/title/tt0056241/mediaviewer docs/gallery.json"
```

### Run Tests
```bash
./gradlew test
```

## ⚡ GitHub Actions Automation

The repository includes a ready-to-run GitHub Actions workflow (`.github/workflows/deploy-pages.yml`):

1. Go to the **Actions** tab in your GitHub repository.
2. Select **"Scrape IMDb & Deploy to GitHub Pages"**.
3. Click **Run workflow**, paste any IMDb URL or ID, and run.
4. The workflow will scrape the photos, generate `docs/gallery.json`, and update your live GitHub Pages gallery automatically!
